# Getting started

Two steps: run the server, then point your Nx workspace at it.

## 1. Run the server

Pick one:

- [Docker](../deployment/docker.md): fastest, uses the pre-built image.
- [Build from source](build-from-source.md): compile the Go binary yourself.

## 2. Connect Nx

Follow [Configure your Nx workspace](configure-nx.md) to set the environment variables Nx needs.

!!! tip
    Start without authentication on `localhost` to check everything works, then enable [authentication](../api/authentication.md) before exposing the server.
